Behind the scenes

How our AI agents work

01
🛡️

Input Guardrail

A supervisor agent validates whether your request is a valid travel query, blocking unrelated or unsafe prompts.

02
✈️

Flight Agent

Connects to AviationStack via MCP to retrieve real-time airport, airline, and route information.

03
🏨

Hotel Agent

Searches for accommodations using Tavily's web-search MCP to find the best options for your budget.

04
☁️

Weather Agent

Fetches live weather and 5-day forecasts from OpenWeatherMap to help you pack smart.

05
💰

Budget Agent

Analyses trip feasibility, identifies cost categories, and provides money-saving recommendations.

06
✅

Human-in-the-Loop

You review the draft itinerary and approve or request revisions before the final plan is generated.
